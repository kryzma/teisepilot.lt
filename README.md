# teisepilot.lt

Landing page for teisepilot.lt — LT legal AI assistant for advocates.

## Local preview

```bash
open index.html
# or
python3 -m http.server 8000
```

## Deployment

Hosted on GitHub Pages.

- Default URL: https://kryzma.github.io/teisepilot.lt/
- Custom domain: teisepilot.lt (after DNS setup — add CNAME file with `teisepilot.lt` and configure DNS)

## Updating

Edit `index.html`, commit, push to `main` — Pages auto-deploys within ~1 min.
